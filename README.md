# PNG Squeeze — Squeeze screenshots into the smallest PNG

A Node stdlib-only program that losslessly re-encodes 1280×720 RGBA screenshots into the smallest PNG it can — an entry for the make.fun bounty "Squeeze screenshots into the smallest PNG, 27 November 2026".
